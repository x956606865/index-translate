# 当前页面临时锁定语音识别语言

## 目标与实施

默认保持 Auto，允许用户在插件弹窗指定当前页面的语音识别语言，以处理开头短暂英文影响后续日语识别等场景。提供原生引擎支持的 11 种语言，不默认固定日语。

- 弹窗新增「声音识别语言（当前页面）」，通过内容脚本读取/修改选择。选择只保存在当前文档内存，关闭弹窗不丢失，也不影响其他标签页或全局翻译源/目标语言。
- 暂停/继续、拖动进度、停止后重启以及九分钟语音会话续接保持选择。刷新、pagehide 和 URL 改变后恢复 Auto；URL 切换由消息入口和 750ms 检查发现，同时停止旧会话。旧弹窗 URL 不匹配时拒绝改写。
- 识别中改选语言复用已授权采集流并重建语音会话，清掉旧转写、待译队列和短语计时器。模型首次加载期间改选会更新待启动意图，并取消返回的过期语言会话后重新启动。
- 后端请求体新增可选 language，默认 Auto；服务层校验后透传原生引擎并在响应确认。同一校验类型用于 HTTP 请求模型与服务层，不修改原生模型、分段策略或 VAD。
- 明确指定语言时，插件必须收到后端同值确认，否则取消会话并提示更新后端。Auto 仍兼容不回传 language 的旧后端。

## Impact analysis

- 插件：`popup.html/js` 提供选择入口；`video.js` 管理页面内存状态和重启；`background.js` 贯通初始启动/重启/续接与过期结果取消；`protocol.js` 校验引擎语言值。
- 后端：`app/server.py` 的可选严格请求体；`app/speech_service.py` 的校验、透传和响应确认。旧调用无 body 或 `{}` 设计上保持 Auto，未修改鉴权/owner 隔离。
- 记录更新：README、能力说明、协议说明、索引和本 mini。保留上一个任务尚未提交的日语低延迟修改及测试。
- 手动交付：用户需同步两端上述业务文件，并保留上次插件的 `speech_phrases.js` 修改；手动重启后端、重新加载扩展并刷新视频页。未操作运行副本、部署、依赖安装、数据库或 Git 状态。

## Regression risks

- 选错语言或视频主要语种变化时，固定语言可能降低准确率；用户可改选或恢复 Auto。混合语种词汇仍由原生模型处理，不能保证固定语言能修正所有转写。
- 改选会清除旧会话尚未提交的内容，重建时会短暂等待；已有译文不会被重新识别纠正。
- 页面边界按文档生命周期和完整 URL 判断，同页面查询参数/hash 变化也会重置；仅播放器内部换源、URL 未变时仍保持该页选择。
- 弹窗关闭、页面节流和采集权限等真实浏览器行为仍需实机验证。HTTP 请求体框架校验没有在本机实际运行（缺少 FastAPI/Pydantic），未安装依赖。
- 旧后端只兼容 Auto；手动锁定需要本次后端更新。后端内置更新继续禁用，插件更新提示保持现状。
