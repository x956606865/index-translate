# 项目能力

## 已有功能

- 网页正文翻译、取消与还原；缓存和译文按原文 hash、服务 identity 和设置隔离。
- 局部翻译：单独轻按并松开 Alt（Mac：Option），优先翻译选中文字，无选区时翻译鼠标所在段落，在原文段落下方以现有双语对照样式显示结果，其他段落已完成的译文保留。不会开启整页扫描；输入框/可编辑区域、组合键不触发。Escape/停止取消在途局部任务；还原页面和路由切换清除局部译文，启动整页翻译时由整页输出接管。已启用的站点自动翻译仍按原规则运行。
- HTML5 视频字幕翻译，以及通过 tabCapture/offscreen 采集视频声音、R2T2 转写并翻译。
- WebUI 管理模型目录、设备、精度、校验、预热、卸载和模型下载。
- 插件可连接 localhost、127.0.0.1 及 RFC1918 私有 IPv4；后端公开接口默认端口 8098，内部语音 worker 固定回环。

## 两端流程

用户设置服务地址并输入配对码 → 插件取得 token 和服务 identity → background.js 发起翻译任务或语音 session → 后端队列调用翻译模型，语音请求经 bridge 进入独立 worker → 插件校验结果并回写网页/字幕。

默认固定配对码为 246810，可用 INDEX_TRANSLATE_PAIR_CODE 覆盖；有效配对码不因成功使用失效。错误尝试受进程内每 60 秒 20 次限制。详情见后端历史修复记录。

## 维护现状与边界

后端自动/手动代码更新已禁用；模型下载功能仍存在。插件仍在安装、启动、定时及手动入口查询上游 Release 并显示更新提示。当前是保留现状的源码导入，未修改插件更新行为。

保留 UTF-8 尾部截断的有界重试/回退及 VAD 线程限制；没有证据证明已在 i9-14900K / RTX 5080 上消除 CPU 满载。历史文档中的 RTX 5090 Laptop 性能值不等于本机测试结果。
